# 诗词格律练习 · 格律考核训练页

> 颜真卿集字题名 · 纯前端 · 免后端 · 免注册

**在线体验：<https://yu-403.github.io/gelv-practice/>**

面向《古代汉语》课程「格律」考核的纯前端练习网页，覆盖两项考核训练：

1. **诗句平仄标注** —— 在七言诗（近体/古体）上逐字标注平仄，限时 3 分钟，失误 ≤ 3 字为通过
2. **入声字判别** —— 从 15 个字中挑出全部入声字，可选 15/30/45/60 秒或不限时，零失误为通过

所有数据存浏览器本地，无服务器、无账号、无网络依赖。

## 🎯 两项考核

### 一、诗句平仄标注

- 逐字点击格子循环「空 → 平 → 仄 → 空」，在七言诗上标注每字平仄
- 可选题库任一篇目专练，或随机抽题
- 限时 3 分钟（可关），失误 ≤ 3 字通过
- 支持「一联一行」对联式排版、答案对照

### 二、入声字判别

- 15 个字中挑出全部入声字（含 3–12 个入声字 + 干扰字）
- 干扰字与答案字今读声调相同，只凭入声知识分辨
- 可选时长；零失误通过
- 批改页网格重建，标出「漏选」「误选」

## 🏗 数据来源与可靠性

数据是本题库的核心，来源可审计：

| 数据 | 来源 | 处理 |
|:-----|:-----|:-----|
| 诗句与平仄 | 喻守真《唐诗三百首详析》原书 PDF | 2400dpi 影像逐字转录，逐首核验 |
