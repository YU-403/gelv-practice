# 诗词格律练习 · 格律考核训练页

> 颜真卿集字题名 · 纯前端 · 免后端 · 免注册

**在线体验：<https://yu-403.github.io/gelv-practice/>**  
**题库版本：2026-10-18**

面向《古代汉语》课程「格律」考核的纯前端练习网页，覆盖两项训练：

1. **诗句平仄标注**：在七言诗上逐字标注平仄，限时 3 分钟，失误 ≤ 3 字为通过。
2. **入声字判别**：从 15 个字中挑出全部入声字，可选时长与题量，零失误为通过。

页面不需要后端和账号，练习记录保存在浏览器本地；练习过程中不向第三方发起网络请求。反馈表单由用户主动点击后在新标签页打开。

## 🎯 两项考核

### 一、诗句平仄标注

- 逐字点击格子循环「空 → 平 → 仄 → 空」，也可用键盘 `A / D / S / Backspace`
- 按篇目专练，或随机抽题
- 限时 3 分钟（可关闭），失误 ≤ 3 字通过
- 批改页显示：本人作答、正确答案、入声字说明、本题练习次数与最好成绩
- 标错的字进入薄弱字池，可进入「薄弱字专练」逐字重考；连续答对 2 次移出

### 二、入声字判别

- 固定 15 个格子，其中包含入声字与非入声干扰字
- 题量可选：考核档（3–6 个随机）、3 个、6 个、9 个、12 个
- 时长可选：15 / 30 / 45 / 60 秒或不限时
- 零失误通过
- 批改页标出「漏选」「误选」「两读」；答错字进入错题池
- 「错题专练」只从错题池出题，答对清出

## 🏗 数据来源与判定口径

| 数据 | 来源与处理 |
|:-----|:-----|
| 诗句与平仄 | 喻守真《唐诗三百首详析》（2005 年 9 月第 2 版），依据书影逐字录入、逐首核验 |
| 单字平仄 / 两读 / 入声 | 参校《平水韵》（佩文韵府）等韵书资料 |
| 入声练习池 | 281 个常用入声字；另设 175 个非入声干扰字 |
| 参照表 | 入声参考 1618 字、两读参考 198 字，用于批改说明与标注 |

**判定规则**

1. 诗句与平仄标注以喻守真《唐诗三百首详析》为第一依据。
2. 两读字按“有入声读法即计入声（仄）”处理，这是练习规则，不是标注错误。
3. 繁体界面按实际显示的字形给标注；简体界面按简体字头给标注。
4. 印本差异、繁简归并字与录入误差可能造成个别差异，核实后会修正并更新题库版本。

> 校对原则：以权威材料本身为唯一权威源；OCR 与查表仅作提示，逐字核对，冲突回原书影像复核。

## ⚠️ 已知边界

- **印本差异**：同一著作不同版次或印次可能存在个别字形、符号差异。
- **两读字**：本练习按“有入声读法即计入声”处理，可能与只按单一读音判断的习惯不同。
- **繁简字形**：个别字（如「只 / 隻」）在繁简界面下的归属可能不同。
- **提取误差**：录入与识别环节仍可能存在疏漏。

若发现某字与你的本子不一致，欢迎通过首页「反馈与纠错」提交篇目、句序和字。
